# Ezhuchi Mozhi — Tamil Status & Quotes

A simple offline-first Android app starter built with Kotlin and Jetpack Compose.

## Features
- Tamil quote categories: காதல், காதல் தோல்வி, தன்னம்பிக்கை, வாழ்க்கை
- Search quotes
- Copy and Android share sheet
- Favorites stored locally
- No API keys or server required

## Build
Open this project in Android Studio, or use the included GitHub Actions workflow to build a debug APK.

Package: `com.tavrixlabs.ezhuchimozhi`

> This is a starter project. Test the generated APK on a real device before any Play Store release.
